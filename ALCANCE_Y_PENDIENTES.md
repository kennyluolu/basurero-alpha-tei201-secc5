# Alcance y pendientes de entrega
**Implementado o probado parcialmente:** ESP8266, HC-SR04, web local, LEDs verde/rojo.
**No validado:** LED azul, mediciones estables, sistema de compactación y pruebas de usuarios.
**Documentación pendiente:** enlace y archivo Fusion 360 definitivo, esquemático real, BOM con costos, fotografías, medidas físicas, integrantes/roles, informe y presentación.

El sistema **no debe describirse como compactador funcional** mientras no exista mecanismo probado.
