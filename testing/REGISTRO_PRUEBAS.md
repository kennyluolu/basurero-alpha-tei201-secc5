# Registro de pruebas — Prototipo Alpha

**Criterio:** separar lo observado o informado por el equipo de lo que falta medir. No se inventan fechas, porcentajes, lecturas, cantidades de ensayos ni aprobaciones.

| Prueba | Evidencia/estado actual | Próximo registro necesario |
|---|---|---|
| Encendido y programación de ESP8266 | Equipo indica placa actual configurada y prototipo montado; hay código y video/fotos en el repositorio | Fecha, alimentación y captura del monitor serial |
| HC-SR04 | Código implementa lectura y validación de distancia; hay evidencia audiovisual del montaje | Medir distancias conocidas y anotar valor real vs. lectura |
| LEDs verde/rojo | Salidas programadas para rangos de llenado; montaje mostrado | Probar físicamente cada umbral y registrar resultado |
| LED azul | **Falla física informada** | Revisar polaridad, resistencia, cableado y LED; registrar diagnóstico |
| Wi-Fi y panel web | Servidor programado con AP `Basurero-Alpha` e IP `192.168.4.1`; evidencia del proyecto | Captura fechada de conexión y actualización de porcentaje |
| Sin lectura del sensor | Caso de error contemplado en código | Ejecutar ensayo reproducible y registrar resultado |
| Servo SG90 / compactación | **No integrado ni validado** como mecanismo de compactación | Diseñar mecanismo y protecciones antes de ensayar |
| Demostración académica | Profesores vieron el prototipo y recibieron explicación, según el equipo | Anotar fecha, observaciones y comentarios concretos si se recuerdan |
