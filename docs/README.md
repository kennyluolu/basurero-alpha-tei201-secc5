# Documentos finales — TEI201

En esta rama la documentación principal está en [`entrega_final/`](../entrega_final/README.md).

Entregables que aún deben incorporarse después de validar el prototipo real:
- `docs/reporte_final.pdf`: reporte técnico final siguiendo pauta Avance #3.
- `hardware/esquematico.pdf`: circuito real exportado desde Fritzing/KiCad/EasyEDA.
- `diseno-3d/planos.pdf`: vistas ortogonales, cotas, escala y tolerancias.
- `diseno-3d/renders/`: vista exterior e interior/explosionado del modelo validado.
- `testing/evidencias/`: fotografías de 3 ángulos, logs, gráficas y demo.

No subir archivos vacíos con extensión PDF únicamente para cumplir checklist: cada uno debe corresponder a evidencia real.
