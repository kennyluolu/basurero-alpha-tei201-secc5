# Diseño 3D histórico — etapa Alpha

Esta carpeta conserva el archivo original de Fusion 360: [Basurero Compactador.f3d](Basurero%20Compactador.f3d).

En la revisión del 22/11/2026, GitHub mostró que el archivo F3D aquí y la copia en [diseno-3d](../diseno-3d/README.md) comparten el mismo blob. Se mantienen ambas rutas para preservar la estructura anterior; no se ha eliminado ni reemplazado el original.

## Ruta de trabajo de entrega final

Usar [diseno-3d](../diseno-3d/README.md) para la memoria del mecanismo y para documentar los entregables finales. El modelo actual se describe como Alpha y aún no se ha abierto en Fusion para comprobar geometría, parámetros o correspondencia con las dimensiones físicas.

Antes de llamarlo gemelo final, abrirlo, verificar las cotas reales del papelero, completar los componentes y exportar planos y renders.
